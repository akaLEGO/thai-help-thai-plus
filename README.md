# เครื่องคำนวณ "ไทยช่วยไทยพลัส" (60/40)

เว็บแอปหน้าเดียว (static) สำหรับช่วยคำนวณสิทธิโครงการ "ไทยช่วยไทยพลัส" แบบ 60/40
(รัฐช่วย 60% / ผู้รับสิทธิจ่ายเอง 40% ผ่านแอปเป๋าตัง)

## ฟีเจอร์

- **คำนวณยอดที่ต้องจ่าย** — กรอกยอดต่อครั้ง แสดงส่วนรัฐช่วย (60% สูงสุด 200 บาท/วัน) และส่วนที่จ่ายเอง พร้อมเตือนเมื่อยอดซื้อเกิน ~333 บาท/วัน (รัฐช่วยแตะเพดาน)
- **หารกันหลายคน (split bill)** — กระจายบิลให้แต่ละคนจ่ายผ่านเป๋าตังของตัวเองเพื่อดึงสิทธิรัฐได้สูงสุด ส่วนเกินเติมเงินจ่ายในแอปได้ พร้อมสรุปรายคน
- **ติดตามสิทธิคงเหลือ** — กรอกยอดที่รัฐช่วยไปแล้วในเดือนนี้ เพื่อดูสิทธิคงเหลือ

## เงื่อนไขโครงการ

| รายการ | วงเงิน |
| --- | --- |
| ต่อวัน (รัฐช่วยสูงสุด) | 200 บาท/คน (ซื้อได้ถึง ~333 บาทที่ยังได้สิทธิเต็ม) |
| ต่อเดือน (รัฐช่วย) | 1,000 บาท/คน |
| รวม 4 เดือน | 4,000 บาท/คน |
| ระยะเวลา | 1 มิ.ย. – 30 ก.ย. 2569 |

## รันในเครื่อง

เป็นไฟล์ static ล้วน เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย หรือเสิร์ฟด้วย:

```bash
npx serve .
```

## เทคโนโลยี

HTML/CSS/JavaScript ล้วน ไม่มี build step — ฟอนต์ Kanit + Sarabun จาก Google Fonts

## ข้อจำกัดความรับผิด

เป็นเครื่องมือช่วยคำนวณเบื้องต้นตามเงื่อนไข 60/40 เท่านั้น โปรดยึดยอดและสิทธิจริงจากแอป "เป๋าตัง" เป็นหลัก
